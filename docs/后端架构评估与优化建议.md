## 2. 核心性能瓶颈分析

### 2.1 数据库性能瓶颈 ⚠️⚠️⚠️ (高优先级)

#### 问题描述
```python
# execute_service.py Line 83-84
result = await db.execute(select(Tool).where(Tool.tool_id == tool_id))
tool: Optional[Tool] = result.scalars().first()
```

**每次工具执行都查询数据库**，而工具元数据变更频率极低（通常只在同步时变更）。

#### 性能影响
- 数据库成为瓶颈，特别是并发请求高时
- 平均增加 10-50ms 延迟
- 数据库连接池可能耗尽

#### 优化方案

**方案A：应用层缓存（推荐）**
```python
# 使用 lru_cache 或 Redis
from functools import lru_cache
from typing import Optional
import time

class ToolCache:
    def __init__(self, ttl: int = 3600):
        self._cache: Dict[str, Tuple[Tool, float]] = {}
        self._ttl = ttl
    
    async def get_tool(self, tool_id: str, db: AsyncSession) -> Optional[Tool]:
        """带TTL的工具缓存"""
        now = time.time()
        if tool_id in self._cache:
            tool, cached_time = self._cache[tool_id]
            if now - cached_time < self._ttl:
                return tool
        
        # 缓存失效，从数据库加载
        result = await db.execute(select(Tool).where(Tool.tool_id == tool_id))
        tool = result.scalars().first()
        if tool:
            self._cache[tool_id] = (tool, now)
        return tool
```

**预期收益**：
- ✅ 响应时间减少 20-50ms
- ✅ 数据库负载降低 70-90%
- ✅ 支持更高并发
- 💰 投入：2人日，收益：显著

#### 优化方案

**方案A：连接池实现**
```python
class MCPConnectionPool:
    def __init__(self, max_connections_per_server: int = 3):
        self._pools: Dict[str, asyncio.Queue] = {}
        self._max_connections = max_connections_per_server
    
    async def get_connection(self, server_name: str):
        """从连接池获取连接"""
        if server_name not in self._pools:
            self._pools[server_name] = asyncio.Queue(maxsize=self._max_connections)
        
        pool = self._pools[server_name]
        try:
            # 尝试获取空闲连接
            return await asyncio.wait_for(pool.get(), timeout=1.0)
        except asyncio.TimeoutError:
            # 无空闲连接，创建新连接
            return await self._create_connection(server_name)
    
    async def return_connection(self, server_name: str, conn):
        """归还连接到池"""
        if await self._validate_connection(conn):
            await self._pools[server_name].put(conn)
        else:
            await self._close_connection(conn)
```

- ✅ 连接建立开销减少 80%

### 2.4 异步任务处理 ⚠️ (中优先级)

#### 优化方案

**方案A：简单异步队列**
```python
# 使用 asyncio.Queue 实现简单任务队列
class TaskQueue:
    def __init__(self):
        self._queue = asyncio.Queue()
        self._results: Dict[str, Any] = {}
        self._workers = []
    
    async def start_workers(self, num_workers: int = 3):
        """启动工作协程"""
        for i in range(num_workers):
            worker = asyncio.create_task(self._worker(i))
            self._workers.append(worker)
    
    async def submit_task(self, task_id: str, tool_id: str, params: dict) -> str:
        """提交任务并立即返回任务ID"""
        await self._queue.put((task_id, tool_id, params))
        return task_id
    
    async def get_result(self, task_id: str, timeout: float = 30.0):
        """轮询获取任务结果"""
        start_time = time.time()
        while time.time() - start_time < timeout:
            if task_id in self._results:
                return self._results.pop(task_id)
            await asyncio.sleep(0.1)
        raise TimeoutError(f"Task {task_id} timeout")
```

```python
from typing import Optional, Dict, Tuple
import time
from app.models.tool import Tool

class ToolCache:
    _instance = None
    
    def __new__(cls):
        if cls._instance is None:
            cls._instance = super().__new__(cls)
            cls._instance._cache = {}
            cls._instance._ttl = 3600  # 1小时
        return cls._instance
    
    def get(self, tool_id: str) -> Optional[Tool]:
        if tool_id in self._cache:
            tool, cached_time = self._cache[tool_id]
            if time.time() - cached_time < self._ttl:
                return tool
        return None
    
    def set(self, tool_id: str, tool: Tool):
        self._cache[tool_id] = (tool, time.time())
    
    def invalidate(self, tool_id: str = None):
        """清除缓存"""
        if tool_id:
            self._cache.pop(tool_id, None)
        else:
            self._cache.clear()

tool_cache = ToolCache()

# 在 execute_service.py 中使用

        tool = result.scalars().first()
        if tool:
            tool_cache.set(tool_id, tool)
    # ...继续执行
```

## 8. 具体代码改进示例

### 8.1 当前代码问题示例

#### 问题1：重复数据库查询
```python
# ❌ 当前实现 - execute_service.py
async def execute_tool(self, tool_id: str, params: Dict, ...):
    # 每次都查数据库
    result = await db.execute(select(Tool).where(Tool.tool_id == tool_id))
    tool = result.scalars().first()
    # ...
```

#### 改进方案
```python
# ✅ 改进后 - 使用缓存
async def execute_tool(self, tool_id: str, params: Dict, ...):
    # 先从缓存获取
    tool = await tool_cache.get(tool_id)
    if not tool:
        result = await db.execute(select(Tool).where(Tool.tool_id == tool_id))
        tool = result.scalars().first()
        if tool:
            await tool_cache.set(tool_id, tool)
    # ...
```

---

#### 问题2：阻塞式长任务
```python
# ❌ 当前实现 - execute_service.py
async def execute_tool(self, tool_id: str, params: Dict, ...):
    # 同步执行，可能需要10秒+
    result = await mcp_client.execute_tool(...)
    return ExecuteResponse(result=result)
```

#### 改进方案
```python
# ✅ 改进后 - 异步任务
@router.post("/execute/async")
async def execute_tool_async(request: ExecuteRequest):
    task = execute_tool_task.delay(
        request.tool_id,
        request.params,
        current_user.id
    )
    return {
        "task_id": task.id,
        "status": "pending",
        "status_url": f"/api/v1/tasks/{task.id}"
    }

@router.get("/tasks/{task_id}")
async def get_task_status(task_id: str):
    task = AsyncResult(task_id)
    return {
        "status": task.state,
        "result": task.result if task.ready() else None
    }
```

#### 问题3：配置日志过多
```python
# ❌ 当前实现 - config.py
def __init__(self, **data: Any):
    super().__init__(**data)
```

```python
def __init__(self, **data: Any):

        logger.debug(f"MCP_SERVERS_PATH={self.MCP_SERVERS_PATH}")
        logger.debug(f"DATABASE_NAME={self.DATABASE_NAME}")
    else:
        logger.info(f"应用启动: {self.APP_NAME} v{self.VERSION} ({self.ENV})")
```
