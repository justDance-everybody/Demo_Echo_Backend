# 生产环境部署指南

本文档提供 Echo Backend 在生产环境的完整部署方案。

## 🚀 部署方案

### 方案一：systemd 服务（推荐 Linux）

#### 1. 自动安装

```bash
# 使用管理脚本生成配置
./entrypoint.sh systemd

# 安装服务（入口脚本会在 Backend/backend 下生成 backend-api.service）
sudo cp backend/backend-api.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable backend-api
sudo systemctl start backend-api
```

#### 2. 手动配置

创建服务文件 `/etc/systemd/system/echo-backend.service`:

```ini
[Unit]
Description=Echo AI Backend Service
After=network.target mysql.service

[Service]
Type=simple
User=your_user
WorkingDirectory=/path/to/Backend/backend
Environment=PATH=/path/to/Backend/.venv/bin
ExecStart=/path/to/Backend/.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port ${APP_PORT:-3000}
Restart=always
RestartSec=3
StandardOutput=append:/path/to/Backend/logs/backend.log
StandardError=append:/path/to/Backend/logs/backend.log

[Install]
WantedBy=multi-user.target
```

#### 3. 管理命令

```bash
# 启动服务
sudo systemctl start echo-backend

# 停止服务
sudo systemctl stop echo-backend

# 重启服务
sudo systemctl restart echo-backend

# 查看状态
sudo systemctl status echo-backend

# 查看日志
sudo journalctl -u echo-backend -f

# 禁用服务
sudo systemctl disable echo-backend
```

#### 4. 优势

- ✅ 系统级别管理
- ✅ 开机自启动
- ✅ 自动重启机制
- ✅ 日志集中管理
- ✅ 资源限制配置

### 方案二：Supervisor 进程管理

#### 1. 安装 Supervisor

```bash
# Ubuntu/Debian
sudo apt-get install supervisor

# CentOS/RHEL
sudo yum install supervisor

# macOS
brew install supervisor
```

#### 2. 配置文件

创建 `/etc/supervisor/conf.d/echo-backend.conf`:

```ini
[program:echo-backend]
command=/path/to/Backend/.venv/bin/python -m uvicorn app.main:app --host 0.0.0.0 --port ${APP_PORT:-3000}
directory=/path/to/Backend/backend
user=your_user
autostart=true
autorestart=true
redirect_stderr=true
stdout_logfile=/path/to/Backend/logs/backend.log
stdout_logfile_maxbytes=50MB
stdout_logfile_backups=10
environment=PATH="/path/to/Backend/.venv/bin"
```

#### 3. 管理命令

```bash
# 重新加载配置
sudo supervisorctl reread
sudo supervisorctl update

# 启动服务
sudo supervisorctl start echo-backend

# 停止服务
sudo supervisorctl stop echo-backend

# 重启服务
sudo supervisorctl restart echo-backend

# 查看状态
sudo supervisorctl status

# 查看日志
sudo supervisorctl tail echo-backend
sudo supervisorctl tail -f echo-backend  # 实时日志
```

#### 4. 优势

- ✅ 跨平台支持
- ✅ 简单易用
- ✅ 强大的进程管理
- ✅ Web 管理界面（可选）

### 方案三：Docker 容器化部署

#### 1. Dockerfile

```dockerfile
FROM python:3.9-slim

WORKDIR /app

# 安装系统依赖
RUN apt-get update && apt-get install -y \
    gcc \
    default-libmysqlclient-dev \
    pkg-config \
    && rm -rf /var/lib/apt/lists/*

# 复制依赖文件
COPY backend/requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt \
    && pip install --no-cache-dir git+https://github.com/modelcontextprotocol/python-sdk.git

# 复制应用代码
COPY backend/ .

# 暴露端口
EXPOSE 3000

# 启动命令
CMD ["python", "-m", "uvicorn", "app.main:app", "--host", "0.0.0.0", "--port", "3000"]
```

#### 2. docker-compose.yml

```yaml
version: '3.8'

services:
  backend:
    build: .
    ports:
      - "3000:3000"
    environment:
      - DATABASE_URL=mysql+pymysql://root:password@mysql:3306/echo_ai_db
      - LLM_API_KEY=${LLM_API_KEY}
      - JWT_SECRET_KEY=${JWT_SECRET_KEY}
    volumes:
      - ./backend/logs:/app/logs
    depends_on:
      - mysql
    restart: unless-stopped

  mysql:
    image: mysql:8.0
    environment:
      - MYSQL_ROOT_PASSWORD=yourpassword
      - MYSQL_DATABASE=echo_ai_db
    volumes:
      - mysql_data:/var/lib/mysql
    restart: unless-stopped

volumes:
  mysql_data:
```

#### 3. 部署命令

```bash
# 构建镜像
docker-compose build

# 启动服务
docker-compose up -d

# 查看日志
docker-compose logs -f

# 停止服务
docker-compose down

# 重启服务
docker-compose restart
```

## 🔐 安全配置

### 1. 环境变量安全

```bash
# 生产环境不使用 .env 文件，使用环境变量或密钥管理服务
export DATABASE_URL="mysql+pymysql://user:pass@host:3306/db"
export OPENAI_API_KEY="sk-..."
export JWT_SECRET_KEY="$(openssl rand -hex 32)"

# 或使用密钥管理服务
# AWS Secrets Manager
# Azure Key Vault
# HashiCorp Vault
```

### 2. 数据库安全

```bash
# 创建专用数据库用户
CREATE USER 'echo_backend'@'localhost' IDENTIFIED BY 'strong_password';
GRANT SELECT, INSERT, UPDATE, DELETE ON echo_ai_db.* TO 'echo_backend'@'localhost';
FLUSH PRIVILEGES;

# 使用 SSL 连接
DATABASE_URL=mysql+pymysql://user:pass@host:3306/db?ssl_ca=/path/to/ca.pem
```

### 3. 防火墙配置

```bash
# 只允许必要的端口
sudo ufw allow 22/tcp      # SSH
sudo ufw allow 80/tcp       # HTTP
sudo ufw allow 443/tcp      # HTTPS
sudo ufw allow 3000/tcp     # API (内部)
sudo ufw enable
```

### 4. Nginx 反向代理

```nginx
server {
    listen 80;
    server_name api.yourdomain.com;

    # 重定向到 HTTPS
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name api.yourdomain.com;

    ssl_certificate /path/to/cert.pem;
    ssl_certificate_key /path/to/key.pem;

    # 安全头
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-XSS-Protection "1; mode=block" always;

    location / {
        proxy_pass http://localhost:3000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        
        # WebSocket 支持
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
    }
}
```

## 📊 监控和日志

### 1. 日志管理

```bash
# 创建日志目录
mkdir -p logs

# 日志轮转配置 /etc/logrotate.d/echo-backend
/path/to/Backend/logs/*.log {
    daily
    rotate 7
    compress
    delaycompress
    notifempty
    create 0640 your_user your_group
    sharedscripts
    postrotate
        systemctl reload echo-backend > /dev/null 2>&1 || true
    endscript
}
```

### 2. 健康检查

```bash
# 定期健康检查脚本
cat > /usr/local/bin/check-echo-health.sh << 'EOF'
#!/bin/bash
HEALTH_URL="http://localhost:3000/health"
MAX_RETRIES=3

for i in $(seq 1 $MAX_RETRIES); do
    if curl -sf "$HEALTH_URL" > /dev/null; then
        echo "✅ Health check passed"
        exit 0
    fi
    sleep 2
done

echo "❌ Health check failed after $MAX_RETRIES attempts"
systemctl restart echo-backend
exit 1
EOF

chmod +x /usr/local/bin/check-echo-health.sh

# 添加到 crontab
echo "*/5 * * * * /usr/local/bin/check-echo-health.sh >> /var/log/echo-health.log 2>&1" | crontab -
```

## 🔄 备份策略

### 数据库备份

```bash
# 每日备份脚本
cat > /usr/local/bin/backup-echo-db.sh << 'EOF'
#!/bin/bash
BACKUP_DIR="/backups/echo"
DATE=$(date +%Y%m%d_%H%M%S)
DB_NAME="echo_ai_db"

mkdir -p "$BACKUP_DIR"

# 备份数据库
mysqldump -u root -p"$MYSQL_PASSWORD" \
    --single-transaction \
    --routines \
    --triggers \
    "$DB_NAME" | gzip > "$BACKUP_DIR/echo_db_$DATE.sql.gz"

# 保留最近 7 天的备份
find "$BACKUP_DIR" -name "echo_db_*.sql.gz" -mtime +7 -delete

echo "✅ Backup completed: echo_db_$DATE.sql.gz"
EOF

chmod +x /usr/local/bin/backup-echo-db.sh

# 每天凌晨 2 点自动备份
echo "0 2 * * * /usr/local/bin/backup-echo-db.sh >> /var/log/echo-backup.log 2>&1" | crontab -
```

## 🚦 零停机部署

### Blue-Green 部署

```bash
# 1. 部署新版本到 green 环境
./entrypoint.sh stop
git pull
pip install -r backend/requirements.txt
alembic upgrade head

# 2. 启动 green 环境（不同端口）
python -m uvicorn app.main:app --host 0.0.0.0 --port 3001 &

# 3. 健康检查
curl http://localhost:3001/health

# 4. 切换 Nginx 代理
# 修改 upstream 配置，指向 3001

# 5. 停止 blue 环境
kill $(lsof -t -i:3000)
```
