## ❓ 常见问题

### Q1: 为什么优先做缓存而不是异步队列？

**A**: 缓存优化投入小（2人日）、见效快（立即降低30%响应时间），且为异步队列优化打基础。异步队列投入较大（7人日），需要前端适配。

### Q2: Redis引入会增加系统复杂度吗？

**A**: 会略微增加复杂度，但收益远大于成本：
- 提供fallback机制（Redis不可用时降级到DB）
- Redis运维成本很低，稳定性高
- 支持未来的分布式部署

### Q3: 是否需要全部完成才能上线？

**A**: 不需要。建议分阶段上线：
- 第1阶段：4人日，立即改善性能，可独立上线
- 第2阶段：17人日，显著提升，可独立上线
- 第3阶段：26人日，长期优化，按需实施

### Q4: 如何衡量优化效果？

**A**: 建议监控以下指标：
- API响应时间（P50, P95, P99）
- 数据库查询次数和耗时
- 缓存命中率
- 并发请求数
- 错误率
