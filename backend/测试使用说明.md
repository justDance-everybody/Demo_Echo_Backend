# 📖 测试使用说明

## 🎯 快速开始

### 运行完整测试

```bash
cd /home/devbox/project/Backend/backend
python test_developer_tool_lifecycle.py
```

这个命令会：
1. ✅ 自动创建3个测试账号（2个开发者 + 1个管理员）
2. ✅ 运行3个完整测试场景
3. ✅ 验证权限控制是否正常工作
4. ✅ 自动清理测试数据
5. ✅ 生成详细的测试日志文件

### 查看测试报告

测试完成后会生成两个文件：

1. **控制台输出** - 实时显示测试进度
2. **日志文件** - `test_developer_tool_lifecycle.log` (JSON格式)

```bash
# 查看日志文件
cat test_developer_tool_lifecycle.log | jq
```

## 🔍 故障排查

### 如果测试失败

1. **检查数据库连接**
   ```bash
   # 确保数据库文件存在
   ls -lh app.db
   ```

2. **检查日志文件**
   ```bash
   cat test_developer_tool_lifecycle.log | jq '.[] | select(.level == "ERROR")'
   ```

3. **手动清理测试数据**
   ```bash
   python -c "
   import asyncio
   from app.utils.db import get_async_db_session
   from app.models.tool import Tool
   from app.models.user import User
   from sqlalchemy import select, delete
   
   async def cleanup():
       async for db in get_async_db_session():
           # 删除测试工具
           await db.execute(delete(Tool).where(Tool.name.like('自动化测试工具%')))
           # 删除测试用户
           await db.execute(delete(User).where(User.username.like('%_auto')))
           await db.commit()
           break
   
   asyncio.run(cleanup())
   "
   ```

## 💡 常见问题

### Q: 测试账号会影响生产数据吗？
A: 不会。测试脚本会自动创建专门的测试账号（用户名包含`_auto`后缀），并在测试结束后自动清理。

### Q: 如何只运行特定的测试场景？
A: 编辑 `test_developer_tool_lifecycle.py`，注释掉不需要的场景即可。

### Q: 可以在生产环境运行这个测试吗？
A: 建议只在开发/测试环境运行。虽然有自动清理机制，但仍可能影响数据库性能。
